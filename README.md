# MoneyBoard

MoneyBoard is a personal finance dashboard built with React. It allows users to track income, expenses, balance, and visualize spending by category.

## Features

- Add income and expense transactions
- Delete individual transactions
- Clear all transactions
- Automatic income, expense, and balance calculation
- Expense chart grouped by category
- LocalStorage persistence
- Responsive layout

## Technologies

- React
- Vite
- JavaScript
- Recharts
- CSS

## How to run

```bash
npm install
npm run dev
